# 画布排布

## 默认组织

- **分区（section）**：业务模块，例如首页、订单、设置。
- **页面（page）**：稳定的业务页面，例如「订单列表」。
- **方案（variant）**：同一页面的不同设计方向，例如 A/B。
- **版本（version）**：某个方案一次固定发布的结果。
- **轮次（round）**：一次发布后新增的版本集合；某一轮只改首页时，设置页沿用旧版本，不强行生成 v2。

## 自动排布

`review_arrange` 的 `mode: "auto"`：

1. 分区按 `order` 从上到下；
2. 同一分区内，页面按 `order` 从左到右；
3. 同一页面的方案横向并排；
4. 同一方案的新版本向下一行；
5. 用户锁定的卡片保持原位，其他卡片避开锁定区域。

新版本发布时默认自动重排；如果用户手动整理过，先读取 `locked`，只对需要的局部传 placements，避免全量重排。

## 手动与锁定

- 拖动卡片后，客户端会把 `x/y` 写回画布。
- 锁定按钮对应 `locked: true`；自动整理不会移动锁定卡片。
- 用户可随时解锁；不要把用户锁定当成临时状态覆盖。

## 坐标

- 卡片坐标 `x/y` 是画布世界坐标（px），`w/h` 是卡片尺寸。
- 批注坐标是图片内归一化坐标（0–1），与画布平移/缩放无关。
- 缩放画布只改变显示比例，卡片内页面视口宽度保持不变；互动 iframe 按原始视口渲染后再缩放。
