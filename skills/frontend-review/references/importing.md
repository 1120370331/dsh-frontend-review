# 导入方式与边界

## 首选：运行中的项目页面

```json
{ "kind": "url", "url": "http://127.0.0.1:5173/orders" }
```

工具会启动一个临时 Chromium（Chrome/Edge），在 `viewport.width × viewport.height`（默认 1440×900）下导航、等待字体和图片、截取 PNG。这个 PNG 是固定版本，之后代码变化不会影响它。

- 开发服务器必须允许无头浏览器访问。
- 需要登录的页面不会被自动授权；把登录态做成测试账号/公开预览页，或用可访问的 HTML/截图源。
- 页面里的 `localhost` 地址必须能被宿主进程访问。
- 截图失败会返回 `status: "failed"` 和可读原因；修好后再发布，不要谎报成功。

## 静态 HTML 副本

```json
{ "kind": "html", "path": "C:/project/dist/preview/home.html", "baseUrl": "http://127.0.0.1:5173/" }
```

工具保存 HTML、注入 `<base>`（如果原本没有），然后截图。HTML 里的相对图片/字体/脚本会按 `baseUrl` 解析。适合设计稿导出页、Storybook 静态页、构建后的单页拷贝。

## 图片/设计稿

```json
{ "kind": "image", "path": "C:/design/home-v2.png" }
```

支持 PNG、JPEG、GIF、WebP。图片会作为该版本的固定画面；无法读取真实 DOM 或交互逻辑，但可以圈画和对比。

## 三种预览方式怎么选

| 目标 | 做法 |
|---|---|
| 只看布局、配色、字号、间距 | `url` 或 `html` 截图；默认总览 |
| 检查 Tab、折叠、弹窗、筛选等状态 | `url` 或 `html` 截图 + 画布「互动」模式中的 iframe |
| 开发服务器实时变化 | `url` + `capture: false`（`live` 版本）；不要让固定版本指向会变化的地址 |

互动 iframe 在画布中按页面原始视口渲染，再整体缩放；不应为了塞进卡片而改变页面自身的 CSS 宽度。对于桌面页，保持 1440px 渲染宽度；手机页用 390px 等真实视口。

## 版本固定规则

发布成功后保留：

- 截图 PNG（以及可选 HTML）；
- 页面尺寸；
- 捕获时的源地址（供人工核对，不作为固定版本的替代）；
- 版本号、页面/方案身份、创建时间；
- 关联的反馈批次。

后续代码改动不会覆盖历史文件。不要手动改 `snapshot.file` 指向的 PNG；需要新画面就发布新版本。
